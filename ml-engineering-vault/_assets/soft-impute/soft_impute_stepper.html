Soft-impute on a 4×4 rank-1 matrix

Truth X = u vᵀ, u = [1,2,3,4], v = [2,1,3,2], four cells hidden. Objective: min ½‖PΩ(X − Z)‖²F + λ‖Z‖*

1. F⁽ᵏ⁾ fed to SVD
2-3. σ (gray) → shrunk σ (purple)
4. Z⁽ᵏ⁾ = U Σλ Vᵀ
hole, current guess observed, copied from X observed, but Z disagrees with X by > 0.25
rank(Z)
RMSE on holes
relative change on holes
Hole values across iterations (dashed = truth)
Pseudo code
Z ← 0
repeat:
    F ← where(observed, X, Z)        # 1. fill holes with current guess
    U, σ, Vᵀ ← svd(F)                # 2. decompose
    σλ ← max(σ − λ, 0)               # 3. soft-threshold singular values
    Z ← U · diag(σλ) · Vᵀ            # 4. rebuild low-rank matrix
until ‖Z − F‖² / ‖F‖² < ε on the holes   # F still holds the previous holes
return where(observed, X, Z)          # Z is only trusted on the holes
